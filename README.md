## 💭 My Story

### From Gaming to Creating 🎮 → 💻

My journey started with video games.  
At first, I was fascinated by how digital worlds, interfaces, systems, and interactions were built.

That curiosity slowly turned into a serious interest in web development, design, and software products.

Today, I focus on frontend development, but my direction goes further.  
I am learning how modern applications are built from UI to logic, from design systems to deployment, and from static pages to AI-integrated user experiences.

For me, frontend is not only about making things look good.  
It is about structure, clarity, responsiveness, accessibility, interaction, and creating interfaces that feel useful and reliable.
